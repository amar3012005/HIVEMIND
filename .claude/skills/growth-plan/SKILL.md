# Growth Plan

Turn the current company state into the smallest credible next growth stage. Treat Campaign Intelligence, SEO, Marketing, Research, Sales, and Branding as specialists, never as the company-level planner.

## Evidence First

1. Read `growth_baseline_latest`; use `growth_baseline_history` only to establish a trend or compare a prior decision.
2. Recall company facts, current offer, ICP, location, policy, active campaigns, existing leads, and prior outcomes.
3. Read only the connected sources relevant to the user request. Use `growth_baseline_collect` for a targeted refresh when the relevant metric is stale or absent. Reserve `full_transfer` for onboarding, reconnects, or an explicit audit.
4. Separate source-backed observations from hypotheses. Never invent channel performance, audience behavior, budgets, conversion rates, or customer proof.

## Choose Intensity

- **Light:** answer a direct question or propose one next action. Do not create a stage.
- **Standard:** diagnose one constraint, state one or two hypotheses, and prepare one bounded stage.
- **Deep:** create or revise a multi-channel stage, delegate specialist work, set a measurement checkpoint, and return an operating contract.

Do not run deep planning merely because the request mentions growth. Match work to evidence and consequence.

## Plan the Next Stage

1. Name the current constraint in one sentence: positioning, reach, conversion, qualified pipeline, retention, or measurement.
2. Select one stage that can resolve it within 7 to 30 days. Do not create a giant fixed roadmap.
3. Create at most three testable hypotheses. Each must include evidence, confidence, expected signal, threshold, and a falsification condition.
4. Choose the minimum specialist rooms needed. Delegate a clear bounded outcome; do not invoke every room.
5. Define the operating policy: autonomy mode, allowed channels, publication/approval rule, spend limit, claims/brand constraints, and stop conditions.
6. Define the next checkpoint and exactly which connector metrics decide continue, pause, or iterate.

## Delegate Precisely

- **Campaign Intelligence:** channel plan, executable sequence, creative briefs, schedules, paid/organic execution.
- **SEO Intelligence:** technical/content opportunity, search measurement, page work.
- **Marketing or Branding:** positioning, message architecture, content themes, proof requirements.
- **Research:** competitors, audience, market, regulatory, and evidence gaps.
- **Sales or Outreach:** existing lead segmentation, follow-up, and pipeline actions. Respect existing first-contact and approval policy.

Send each specialist the stage objective, evidence references, constraints, required artifact, deadline/checkpoint, and success measure. A specialist report is input to HQ; it does not replace the Growth Plan.

## Monitor and Adapt

Use scheduled work only for active stages or campaigns:

- active publishing campaign: daily measurement;
- organic stage: weekly measurement;
- connector error, rejection, or material anomaly: immediate targeted review;
- stage checkpoint: compare results with the stated thresholds.

At a checkpoint choose one: continue, scale, pause, repair, change channel, change hypothesis, or close the stage. Write the evidence and decision to the Growth Journal. Keep the global goal stable while treating stages and campaign actions as experiments.

## Required Output

Use the exact headings in [references/operating-contract.md](references/operating-contract.md). Keep the summary readable for a company owner, then include the machine-readable contract. Do not claim execution occurred unless a connector/action result proves it.
