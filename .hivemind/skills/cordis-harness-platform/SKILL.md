# Cordis Harness platform

Use native Cordis extension seams: plugins own capabilities, tools have one validated schema and
canonical result, and profile configuration owns behavior. Do not patch the native agent loop.

Expose only the context and tools needed at each stage. Keep connected-app discovery, selected-tool
execution, receipts, approvals, and workflow state typed and durable. Preserve native Harness
conversation behavior; HIVE composition must not replace unrelated native UI or session semantics.
