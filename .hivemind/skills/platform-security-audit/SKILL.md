# Platform security audit

Use for security-sensitive changes or audit requests. Verify boundaries end-to-end: private origin,
trusted host/origin checks, signed ticket or JWT validation, authorization scoping, rate limits, and
secret handling. Test denied cross-tenant and replay cases. Record findings with the exact boundary
and remediation; do not broaden routine feature work into an unrelated audit.
