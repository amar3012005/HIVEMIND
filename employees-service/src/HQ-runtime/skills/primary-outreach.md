# Primary Outreach

Use when HQ receives an instruction to acquire clients, leads, prospects, or
customers. Treat the instruction location as authoritative; when it is absent,
use the company profile location.

## Procedure

1. Read the company offer, ICP, positioning, location, prior leads, and latest
   growth evidence.
2. Require a live prospect-discovery capability before claiming local targets.
3. Reuse existing organization leads before discovering duplicates.
4. Qualify prospects against the ICP and retain the reason each prospect fits.
5. Require a connected outreach provider before preparing channel execution.
6. Return a bounded result: qualified targets, evidence, proposed outreach,
   measurable next action, and blockers.

Do not fabricate contacts, claim delivery, or send externally without the
organization's authority policy. Missing capabilities are dependency requests,
not reasons to discard the todo.
