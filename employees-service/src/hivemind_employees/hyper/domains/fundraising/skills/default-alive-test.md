when: the task decides whether to raise, how much, or how long the company has before it must

DEFAULT ALIVE TEST (Graham, *Default Alive or Default Dead?*, 2015):
1. STATE THE THREE INPUTS — cash on hand, current net monthly burn, current revenue growth rate month over month. Mark each verified, modeled, or unknown. Missing an input makes the verdict unavailable, never assumed.
2. PROJECT — hold expenses at today's level and extrapolate revenue at today's growth rate. If revenue crosses burn before cash runs out, the company is DEFAULT ALIVE; otherwise DEFAULT DEAD. Constant headcount is the whole point of the test: a plan that only works with the hires the round pays for is a hope, not a trajectory.
3. NAME THE VERDICT IN PLAIN WORDS — Graham's phrasing: "we are default dead, but we're counting on investors to save us." Never let a growth deck bury the verdict.
4. CHECK THE FATAL PINCH — default dead + slow growth + too little time to fix it. Signals: burn rising faster than revenue, growth flat 3+ months, under 6 months runway. If two hold, cutting burn outranks pitching — raising while default dead with flat growth is the hardest raise there is.
5. SET THE ASK FROM THE MILESTONE — the round buys the specific evidence the next round needs, plus buffer. State it as "X months to milestone Y at burn Z", not a round size, because growth rate is what investors extrapolate.
6. GUARD THE BIGGEST KILLER — hiring too fast. Any raise plan lists each planned hire and what breaks if it is deferred.
