when: A website URL must be audited for crawlability, indexability, metadata, headings, links, images, or structured data.
---
Start from deterministic scan evidence. Separate site-wide, template, and page findings. Prioritize blocked indexing, error responses, conflicting directives, and repeated template defects before low-severity hygiene. For every fix state affected scope, observed evidence, implementation owner, effort, dependency, and the exact rescan condition that proves resolution. Never infer Google index status from a public crawl.
