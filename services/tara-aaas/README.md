# tara-aaas — TARA voice orchestrator (self-hosted AaaS)

Single-service voice round-trip for the TARA voice agent. Previously lived only
on the prod box (`/opt/tara-aaas`); now version-controlled here.

```
browser audio ──WS──▶ Groq Whisper STT (VAD/endpointing)
   final transcript ─▶ HIVEMIND core  POST /api/tara/stream  (the LLM brain)
        token text  ─▶ Cartesia TTS
             audio  ─▶ WS back to browser
```

- **Stack:** FastAPI + uvicorn (`tara_aaas.app:app`), Python 3.11.
- **STT:** Groq Whisper. **TTS:** Cartesia. **LLM/recall:** HIVEMIND core (not here).
- **Entry:** `tara_aaas/voice_ws.py` (`handle_voice`) — session state machine,
  barge-in, call-history ingest, and the opening **greeting** (`greet()`), which
  is generated by core in the selected language + active skill persona
  (`POST /api/tara/stream` with `greeting:true`).
- **Core client:** `tara_aaas/tara_stream.py`.

## Infra (prod box)

| | |
|---|---|
| Container | `tara-aaas` (image `tara-aaas:latest`) |
| Network | `hmtest` |
| Port | `8091 → 8090` |
| Edge | `hivemind-caddy :8050 → /aaas/voice` |
| Restart | `unless-stopped` |
| Secrets | `/opt/tara-aaas/.env.deploy` (box only, NOT in git) — passed as the container env |

## Deploy

This directory is the source of truth. To ship a change:

```bash
cd services/tara-aaas
./redeploy.sh          # rsync → docker build → recreate container (env preserved)
```

`.env.deploy` and other secrets on the box are never synced or overwritten.
